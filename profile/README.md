# RheinInsights

**Enterprise Retrieval Infrastructure for Secure AI Applications.**

RheinInsights develops software for connecting enterprise knowledge
to AI platforms, vector databases and search engines.

The RheinInsights Retrieval Suite provides scalable enterprise
content ingestion and retrieval across data sources such as
Atlassian, XWiki, OpenProject, Microsoft, OpenText, SAP and 
other enterprise systems.

It is designed for enterprise AI and RAG architectures where precision,
source permissions, access control and data sovereignty matter.

## RheinInsights Retrieval Suite

The Retrieval Suite connects enterprise data sources with retrieval
infrastructure and AI applications.

Typical architectures include:

- Enterprise data sources → RheinInsights → Azure AI Search → AI
- Enterprise data sources → RheinInsights → Elasicsearch → AI
- Enterprise data sources → RheinInsights → OpenSearch → AI
- Enterprise data sources → RheinInsights → Postgres → AI 
- Enterprise data sources → RheinInsights → Qdrant → AI
- Enterprise data sources → RheinInsights → Squirro → AI
- Enterprise data sources → RheinInsights → Weaviate → AI
- Enterprise data sources → RheinInsights → Open WebUI
- Enterprise data sources → RheinInsights → MS Copilot

## Open Source & Integration Projects

This GitHub organization contains integration examples, reference
architectures and selected open-source components from RheinInsights.

The RheinInsights Retrieval Suite itself is commercial software
and is not distributed as source code through GitHub.
